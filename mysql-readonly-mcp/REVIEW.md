## 质量检查

- 语言与语法：使用 Python 3.11 语法，源码通过 AST 语法解析；未运行编译命令或单元测试。
- 接口与契约：三个工具、固定单数据库、明确列序二维行数据、固定错误格式。关闭 SDK 自动结构化输出，避免重复结果影响字节预算。
- 错误处理：配置错误和数据库异常仅返回固定信息/数字错误码；原始异常、凭据和 SQL 不输出。配置文件权限、拥有者、大小及符号链接均校验。
- 边界条件：检查多语句、跨库、未知节点/函数、递归 CTE、通配列、LIMIT 字面量；仅 COUNT(*) 可用。允许 AND/OR/CASE，即使 SQLGlot 将其归类为 Func。
- 连接清理：流式结果未读完时断连，不触发 SSCursor 的排空逻辑；清理驱动结果引用以防析构继续读取断开的流。数据库及客户端均有限时机制。
- 依赖与集成：锁定 MCP SDK 1.30.0、PyMySQL 1.2.0、SQLGlot 30.18.0 和传递依赖，实际依赖已通过临时 HTTP 代理安装到仓库内虚拟环境。运行入口不执行安装命令。
- 可维护性：单文件服务，配置/SQL/结果处理职责明确，安全限制为固定常量。PyMySQL 私有 socket/result 接口是明确的升级复核点。

## 风险与未验证项

- 已验证：Python AST 语法、三个 TOML 文件解析、Skill 格式、Git diff 空白检查、敏感配置与缓存忽略规则、空配置权限；离线 initialize、三个工具发现、标准输入关闭后正常退出且 stderr 为空。
- 未验证：遵守要求未执行单元测试；没有执行任何真实数据库查询，MySQL 8.0/8.4 认证、TLS、SQL 语义、授权、超时和连接释放仍需环境验收。
- 主要风险：本地代码与 Skill 不是强隔离；只读账号可读的数据仍可能进入模型上下文。全表查询范围需通过数据库权限和脱敏视图控制。
- 返回大小限制不是进程内存硬上限；大型单行数据包仍会被驱动读取。LIMIT 也不限制扫描量，应使用测试库或独立查询副本。
- AST 不展开数据库视图，视图内部引用及函数须由管理员审查。断连不能保证立即停止所有数据库内部工作。
